# Amstrad CPC core for Karabas Go / Mini / Mini G

Amstrad CPC 464 / 664 / 6128 (and later CPC Plus / GX4000) for the Karabas boards
(Xilinx Spartan-6 XC6SLX25, ISE 14.7): a port of the
[renaudguerin Amstrad_MiSTer fork](https://github.com/renaudguerin/Amstrad_MiSTer) of the
[MiSTer Amstrad core](https://github.com/MiSTer-devel/Amstrad_MiSTer).

Work in progress. Credits of the upstream parts: `upstream/CREDITS.md`.
