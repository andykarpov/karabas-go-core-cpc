# Ядро Amstrad CPC для Karabas Go / Mini / Mini G

[English version](README.md)

Amstrad CPC 6128, 664 и 464 для плат семейства Karabas Go (Xilinx Spartan-6 XC6SLX25). Порт [форка renaudguerin Amstrad_MiSTer](https://github.com/renaudguerin/Amstrad_MiSTer) [ядра Amstrad для MiSTer](https://github.com/MiSTer-devel/Amstrad_MiSTer). Только классические модели: часть форка с CPC Plus / GX4000 в нынешнем виде в ПЛИС не помещается.

| Плата | Файл ядра | Видео | Звук |
|---|---|---|---|
| Karabas Go | `cpc.kg` | VGA | I2S ЦАП (PCM5102) |
| Karabas Mini | `cpc.kg` | HDMI | HDMI, аналоговый выход (сигма-дельта) |
| Karabas Mini G | `cpc.kg` | HDMI | HDMI, I2S ЦАП |

Файл ядра лежит в `src/`. Системные ПЗУ трёх моделей (OS, BASIC, AMSDOS) встроены в него. Образы дисков, кассет, снапшотов и ПЗУ в комплект не входят: положите свои на SD-карту в `/cpc`.

Состояние: проверено на Mini G. Сборки для Go и Mini на плате ещё не запускались.

## Возможности

- **Машины:** CPC 6128 (128K), 664 и 464 (64K): Z80 на 4 МГц, Gate Array, CRTC тип 1 или 0, AY-3-8912.
- **Диски:** два дисковода (A и B), образы `.dsk` (обычные и расширенные), чтение и запись: изменения записываются обратно в образ на SD-карте.
- **Кассета:** образы `.cdt`, загрузка со скоростью настоящей кассеты.
- **Снапшоты:** образы `.sna` (только загрузка).
- **ПЗУ расширений:** файлы `.eXX`, как на MiSTer: `.e00` .. `.e1f` кладут ПЗУ в этот слот верхнего ПЗУ (номер шестнадцатеричный); `.ez0` заменяет нижнее ПЗУ и BASIC (например, прошивка 464 на 6128); `.ezz` — как на MiSTer.
- **Видео:** картинка CPC 50 Гц с бордюром, удвоение строк до 1024 x 624 при 50 Гц (31,25 кГц); цветная или монитор зелёный / янтарный / голубой / белый.
- **Звук:** AY в стерео (ABC) и звук кассеты.
- **Управление:** клавиатура, два джойстика (USB-геймпады). Мышь подключена как в ядре MiSTer, но не проверялась.

Пока не сделано: Multiface II, PlayCity, CPC Plus / GX4000.

## Начало работы

1. Скопируйте `cpc.kg` (один файл для Go, Mini и Mini G) в корень SD-карты.
2. Положите свои образы в `/cpc` на SD-карте.
3. Выберите Amstrad CPC в меню ядер. Запускается CPC 6128 в BASIC. Откройте OSD (**Menu+Esc**), выберите диск в пункте Disk A (**Menu+F1**), затем наберите `cat` и `run"имя`.

«Menu» — клавиша Windows на клавиатуре.

Кассета на 6128 или 664: наберите `|tape`, затем `run""` и нажмите любую клавишу; образ выбирается в пункте Tape (**Menu+F3**). 464 читает кассету без `|tape`.

## Меню OSD

| Пункт | Значения | Горячая клавиша |
|---|---|---|
| Disk A, Disk B | образ `.dsk` | Menu+F1, Menu+F2 |
| Tape | образ `.cdt` | Menu+F3 |
| Snapshot | образ `.sna` | Menu+F4 |
| ROM | `.e00` .. `.e1f`, `.ez0`, `.ezz` | Menu+F5 |
| Model | CPC 6128 / 664 / 464 | Menu+M |
| CRTC | Type 1 / Type 0 | |
| Display | Colour GA / Colour ASIC / Green / Amber / Cyan / White | Menu+D |
| Reset | сброс машины | F12 |

Настройки и подключённые диски запоминаются. Смена модели перезапускает машину.

## Клавиатура

Раскладка позиционная: клавиша ПК набирает то, что набирает клавиша CPC на том же месте, а не то, что на ней нарисовано. Некоторые символы на US-клавиатуре:

| CPC | Клавиша ПК |
|---|---|
| `"` | Shift+2 |
| `\|` | Shift+[ |
| `:` | ; |
| `=` | Shift+- |
| `(` | Shift+8 |
| `)` | Shift+9 |

Сброс машины: F12.

## Сборка

Клонируйте с `--recursive` (подмодуль `modules`). ISE 14.7: `cd src && make` для всех плат или `make minig` для одной. Топы Mini и Go (и временная часть их ucf) делаются из топа Mini G скриптом `src/tools/mktops.py`; переведённые исходники (`src/rtl/sv2v`) — `src/tools/sv2v.sh core`; обёртка `emu` MiSTer — `src/tools/make_cpc_emu.py`. Проверки на Verilator: `src/sim/run_boot.sh` (машина до приглашения BASIC), `src/sim/run_disk.sh` (контроллер дисковода против модели монтировщика файлов). План и заметки по устройству — в [docs/PLAN.md](docs/PLAN.md).
